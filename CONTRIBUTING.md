# Contributing

Thank you for helping make GREEN ARMOR Directory Range safer and more useful for students.

1. Keep scenarios self-contained, documented, and limited to fictional identities.
2. Never add real passwords, personal information, or generated `runtime/` artifacts.
3. Keep default Docker networking private, and do not add published ports without a documented alternative security mode.
4. Add CLI tests and clearly describe changes that impact first-boot provisioning.
5. Verify new scenarios with a full `reset --yes` and a student-level end-to-end walkthrough.

By contributing, you agree that your work may be distributed under the repository's MIT License.
